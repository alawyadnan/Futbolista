# Release 500415 — iPhone 1.0.1 (9)

## Changes

- Optional native group notifications through APNs and Firebase Cloud Messaging.
- Explicit opt-in, disabled-by-default initialization, native-only delivery tokens,
  notification status, opt-out and iOS Settings shortcut in Account / admin Settings.
- Admin shortcut to Firebase's free notification composer; manual broadcasts target
  `futbolista_updates`. Saving a match does not automatically send notifications.
- Notification links allow only Dashboard, History or Leaderboard and retain the
  existing unsaved-form navigation guard.
- Genuine additive Firebase iOS registration, FirebaseMessaging 12.19.2 (no Analytics
  product), matching bundle identity, push capability and production APNs linkage.
- Updated bilingual privacy policy and cache version. Existing goals additions,
  statistics, accounts, voting, web Firebase configuration and data rules retained.

## Verification on 2026-09-29

- All 311 automated tests passed (301 app + 10 native).
- Native bundle, Capacitor sync, asset checks and plist validation passed.
- Xcode simulator build and signed device archive succeeded; build 9 uploaded to
  App Store Connect and processed successfully.
- Actual iOS notification prompt and denied-permission recovery verified in the
  simulator. Public real-data browsing remained functional.
- No production Firestore documents were written, no broadcast was sent, no paid
  backend enabled and no APNs private key added to the repository.

## Remaining delivery verification

Production APNs is configured for this bundle only. End-to-end foreground,
background and cold-start delivery on a physical distribution device has not yet
been tested. Perform a separately approved device-only test after installing the
new distribution build; never use a group broadcast as a test.

Users of the original app need this App Store update and must enable notifications.
See `native/store/PUSH-NOTIFICATIONS.md` for sending instructions. Keep existing
free/unlisted distribution and manual release settings unchanged.
