Futbolista 500418 — additional local development, not published

Includes all 500417 improvements plus:

1. Compare directly from the player directory
   Enable comparison mode, select two players, then compare. The selection
   survives searching, sorting and directory scope changes. A third selection
   cannot silently replace either player. Selected names stay visible in a
   compact sticky panel; each can be removed. Returning from comparison restores
   the directory context. Normal player cards still open profiles outside this mode.

2. Redesigned direct-meeting record
   Names, wins and draws are aligned with the green/blue comparison identities.
   A proportion bar summarizes the existing head-to-head record. Added personal
   goal totals from opponent meetings only, excluding same-side and unrelated
   matches. These are not team goals or a new player rating. Empty records do not
   invent a 0–0 match. Existing statistical periods, forms and shared match history
   remain available; direct-meeting totals are explicitly all-time.

3. Recorded group participation in the player profile
   Date cells show the last 12 group matches, starting no earlier than the player's
   first recorded appearance. Played matches retain recorded W/D/L; non-participation
   is a separate neutral state, never a loss. Each cell opens the actual match.
   Separate match IDs on the same date remain distinct. Goal additions and own-goal
   rows never create additional appearances. No attendance data is written.
