# Release 500416 — website table scrolling fix

## Fix

Reproduced disappearing sticky player names in Arabic on iOS 26.4.1 Simulator Safari. A horizontal gesture repainted the missing names. Promoting cells or their ancestors to composited layers did not reliably fix the problem and those experimental changes were removed.

The horizontal scroll container now uses LTR coordinates while the Arabic table retains RTL column order and its right-sticky name column. The renderer restores the correct starting edge, preserves the distance from the name column during data/search updates, and resets to the name column when changing the selected statistic. No scroll listeners, repeated repaint loops, extra player rows or statistical changes.
